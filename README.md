# Requirementsspecificatie – ChocoMasters

## Inleiding

Dit document vormt de centrale ingang van de **Requirementsspecificatie voor ChocoMasters**. 
Het doel van deze opdracht is het gestructureerd vastleggen van de context, processen, requirements en ontwerpen die nodig zijn voor de ontwikkeling van de ChocoMasters-applicatie. De repository is opgezet volgens een duidelijke hoofdstukstructuur, zodat zowel docenten als projectleden eenvoudig inzicht krijgen in de inhoud en samenhang.

De requirementsspecificatie volgt de stappen van Requirements Engineering: van contextanalyse en stakeholders tot processen, domeinmodellen, wireframes en versiebeheer.
